# Invariants

Rules that must hold for every change. Read [core.md](core.md) for every task, then the one rule doc that [AGENTS.md](../../AGENTS.md) names for your task.

| Rule doc | Holds |
| --- | --- |
| [core.md](core.md) | Product-wide rules: the task lifecycle, how agents operate tasks, secrets |
| [processes.md](processes.md) | Approval before action, git, docs, ADRs, README |
| [backend.md](backend.md) | Task API, database, MCP server, logging |
| [frontend.md](frontend.md) | Task board |
| [tooling.md](tooling.md) | Dependencies, run commands, ports, docs checker |

Statuses: `Current` (enforced by code, a test, or a script), `Convention` (checked by a person in review), `Planned` (not enforced yet).
